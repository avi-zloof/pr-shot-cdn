Cast — planning picks the agent team

Before anyone writes code, Cast is the planning step where the orchestrator chooses which agents will run the delivery. That keeps roles explicit instead of improvised mid-run.

  • Dev — implements in the feature worktree only
  • Validator — focused tests and runtime checks
  • Auditor — read-only delivery gate before merge
Plan→Cast→Dev→Validator→Auditor→Out

Tape — the end-of-run story

Tape is the closing artifact: a short workflow story written to docs/runs/<KEY>-tape.md. It captures plan, root cause, fix, tests, and UI evidence so the next person (or auditor) can reconstruct the run without mining chat history.

  • Auditor can require Tape presence before merge
  • Auditor does not author Tape — orchestrator / developer leaves it
  • INT-1235 tape: docs/runs/INT-1235-tape.md
